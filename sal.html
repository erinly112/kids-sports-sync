Kids Sports Sync

Get your kids' sports calendars organized and drive-time reminders added automatically. Setup takes about 10 minutes.

Before you start

Ask Erin to add your Google account

Before setup will work, Erin needs to do two things with your Gmail address:

  1. Add you as a test user — so the Google sign-in step works
  2. Share the credentials file — so the setup script can download it

Just send Erin your Gmail address and wait for her to confirm both are done. Then come back here and continue.

Step 0

Get Claude Code and a Pro subscription

  1. Download the Claude Code desktop app
  2. Sign in or create a Claude account
  3. Upgrade to Pro — the Cowork feature that drives this setup requires it
  4. Open the app and confirm you see a Cowork tab at the top
Step 1

Create a Chrome sandbox profile for Claude

This gives Claude its own browser window, completely separate from your passwords, email, and personal accounts.

  1. Open Chrome
  2. Click your profile photo in the top-right corner
  3. Click Add → Continue without an account
  4. Name it Claude → click Done
  5. A new Chrome window opens in the Claude profile — keep it open
This keeps Claude away from your banking, email, and saved passwords. It only has access to what you give it during setup.
Step 2

Connect Chrome to Cowork

  1. In the Claude Code app, click the Cowork tab
  2. Look at the Context panel on the right side
  3. Click to add a connector and select Chrome — Browser 1
  4. Make sure it's connected to the Claude profile window you just created
Step 3 — Last thing you do

Start setup by typing this into Cowork

Copy and paste this into the Cowork message box and press enter:

Go to github.com/erinly112/kids-sports-sync, download the project, and set it up for me
From here, Claude takes over. It will ask you questions about your kids and their sports teams, and sign you into Google. Just answer the questions and follow any prompts that appear in the browser.

What Claude does from here

You don't need to do anything for these steps — just watch and answer when Claude asks you something.

1

Installs the Claude Chrome extension

Claude navigates to the Chrome Web Store and installs the extension that lets it operate the browser on your behalf.

2

Downloads the project

Claude goes to GitHub, downloads the project files, and sets them up on your computer.

3

Installs software dependencies

Claude installs the Python packages the scripts need to run. This happens in the background.

4

Asks about your family

Claude will ask for your kids' names, which sports teams they're on, your home address (for drive-time estimates), and which Google Calendar should get the reminders. One question at a time.

5

Signs you into Google

A Google sign-in page will open in the Claude browser window. Sign in with the same Gmail address you sent to Erin, then click Allow. That's all — Claude handles the rest. (If you see a warning that the app is unverified, click "Continue" — this is expected during the testing phase.)

6

Tests everything and confirms it's working

Claude runs a test sync and shows you what it found. If anything looks off, it'll help you fix it before finishing.

You're done

Once setup is complete, you can come back to Cowork any time and ask Claude to run a sync, adjust a team, or help with anything else.
